The dashboard is serving

This page came from the farrier binary on your own machine, over loopback. The local control API is served from this same address, so nothing here reaches the network.

Views are on their way

Instance status, replication lag, backup history, drill results, and promotion will live here. Until they land, every one of them runs from the command line:

  • farrier status — instance health and last-backup age
  • farrier backup — capture, encrypt, verify a snapshot
  • farrier drill — rehearse a restore on a scratch host
  • farrier promote — fail over to a new host

Stop the dashboard with Ctrl-C in the terminal that started it.
